## Install

```
/plugin marketplace add Zazaaw/p441z-style-kit
/plugin install p441z-skills@p441z
```

From a shell: `claude plugin marketplace add Zazaaw/p441z-style-kit` then
`claude plugin install p441z-skills@p441z --scope user`.
